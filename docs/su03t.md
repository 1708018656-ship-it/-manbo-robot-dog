# SU-03T 离线语音模块配置（精简版）

精简版用 SU-03T 代替 ASR PRO：模块自己完成"听懂口令"，然后通过串口给 STM32 发一个字节，STM32 就执行对应动作。**模块里的口令需要先在厂商的在线平台上配置好、生成固件并烧进模块**，买来的空白模块不会直接发我们的命令。

## 接线

| SU-03T | 精简版底板 J6 / Blue Pill |
|---|---|
| VCC | VCC（约 4–5.5 V，来自电池经二极管） |
| GND | GND |
| B7（UART TX） | TX → PB11（USART3 RX） |
| B6（UART RX） | RX ← PB10（USART3 TX） |
| MIC+ / MIC- | 驻极体麦克风（模块套件一般自带） |
| SPK+ / SPK- | 8 Ω 小喇叭（模块自带功放）——**语音回复靠它** |

串口参数：**9600 8N1**。引脚以模块丝印和平台说明为准，B6/B7 接反只会收不到命令，不会损坏。

## 平台上的配置

在 SU-03T 厂商（智能公元）的在线平台新建产品，按下表添加命令词。每条命令的"控制详情"设为**串口输出**，内容填对应的**十六进制字节**（一个字节）。"回复语"是模块自己用喇叭说的话，可以随意改，不需要可以留空。

| 唤醒词 | 小呆小呆（可自定义） |
|---|---|

| 命令词（可以多填几个说法） | 串口输出 (HEX) | 对应字符 | 动作 | 回复语示例 |
|---|---|---|---|---|
| 前进 / 往前走 | `66` | `f` | 前进，一直走直到"停"（精简版 10 秒自动停） | 好的 |
| 后退 / 往后走 | `62` | `b` | 后退 | 好的 |
| 左转 | `6C` | `l` | 左转 | 左转 |
| 右转 | `72` | `r` | 右转 | 右转 |
| 停 / 停下 / 站好 | `35` | `5` | **急停**，回到站立 | 停 |
| 起来 / 站起来 | `71` | `q` | 起身 | 来啦 |
| 坐下 | `73` | `s` | 坐下擦脸 | 遵命 |
| 趴下 / 睡觉 | `70` | `p` | 趴下睡觉 | 晚安 |
| 躺下 | `32` | `2` | 卧下睡觉 | 晚安 |
| 打招呼 / 你好 | `6F` | `o` | 打招呼 | 你好呀 |
| 握手 | `6A` | `j` | 交替抬手 | 握手 |
| 跳舞 | `64` | `d` | 跳舞 | 来跳舞 |

## 主动播报（STM32 让模块说话）

除了识别后自动回复，单片机也会在特定时刻通过串口让 SU-03T 说话。在平台上添加以下**串口输入**（收到这串字节就播报对应的话，即平台里的"主动播报 / 串口输入触发播报"），帧格式固定为 `AA 55 <编号> 55 AA`：

| 串口输入 (HEX) | 播报内容（可改） | 什么时候触发 |
|---|---|---|
| `AA 55 01 55 AA` | 小呆来啦 | 开机 |
| `AA 55 02 55 AA` | 走累了，歇一会儿 | 一直走了 10 秒还没听到"停"，自动停下时 |
| `AA 55 03 55 AA` | 好的 | 预留（固件里的通用回应） |

不配置这几条也不影响使用，只是开机和自动停下时不出声。编号定义在 `User/Voice.h`，想加新的提示音照着加一行即可。

## 生成和烧录

1. 平台生成固件后，用 **USB 转 TTL 模块（CH340，约 5 元）** 按平台教程烧录：TTL 的 TX/RX/GND 接模块的 B6/B7/GND，给模块上电后用平台提供的工具烧写。
2. 不想自己烧：很多卖 SU-03T 的店铺提供**按指令表代烧录**，下单时把上表发给店家即可。
3. 烧好后先单独测试：模块接 USB 转 TTL，用串口助手（9600）说"小呆小呆，前进"，应该收到 `66`。

## 小技巧

- 唤醒词后模块会等一段时间接收命令，可在平台调整"唤醒时长"。
- 同一个动作多加几个说法，识别率会高很多。
- 回复语用模块自带的喇叭播放，精简版不需要 SYN6288 也能"说话"。
