# 串口命令协议（唯一权威表）

蓝牙（USART1，PA9/PA10）和语音识别模块（USART3，PB10/PB11）都向 STM32 发送**单个 ASCII 字节**，9600 8N1。
STM32 端实现：`User/ActionTask.c` → `ActionTask_HandleCommand()`（动作），`User/main.c`（模式开关和状态播报）。
ASRPro 端常量：`ASRPro_Code/include/commands.h`，**改协议时两边和本表一起改**。

蓝牙优先于语音：同一轮里两个串口都收到数据时，以蓝牙为准。

## 运动（持续执行，直到收到新命令）

| 字节 | 动作 | 体力 | 开心 |
|---|---|---|---|
| `f` | 前进 | −5/步 | 连续第 6 步起 −3/步 |
| `b` | 后退 | −5/步 | 同上 |
| `l` | 左转 | −5/步 | 同上 |
| `r` | 右转 | −5/步 | 同上 |
| `w` | 前后摇摆 | −5 | +5 |
| `z` | 左右摇摆 | −5 | +5 |
| `d` | 跳舞 | −5 | +5 |

## 模式开关与状态

| 字节 | 功能 |
|---|---|
| `x` / `c` | 打开 / 关闭超声波避障 |
| `H` / `h` | 打开 / 关闭红外防跌落 |
| `K` | 播报开心值 |
| `T` | 播报体力值 |
| `Z` | 播报开心值和体力值 |

## 规则

- 体力 ≤ 0 时只接受睡觉命令（`p` / `2`）。体力上限 500，开心上限 200。
- 数值规则在 `User/PetStats.h`，有主机单元测试 `tests/host/test_pet_stats.c`。
- 语音合成（USART2 → SYN6288）的文本必须是 **GBK** 编码，单帧最多 200 字节。源码里新增中文提示语请写成 `\x` 转义，参考 `User/ActionTask.c`。
